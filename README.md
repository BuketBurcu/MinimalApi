📌 Minimal API Todo Uygulaması
Bu proje, .NET 8 ve C# dilinde geliştirilen basit bir Todo uygulamasıdır. Projede Minimal API yaklaşımı kullanılarak sade, okunabilir ve hızlı bir yapı oluşturulmuştur.

🚀 Özellikler
✅ .NET 8 ile yazılmıştır

✅ Minimal API mimarisi kullanılmıştır

✅ Temel CRUD işlemleri desteklenir (Create, Read, Update, Delete)

✅ top-level statements yapısı tercih edilmiştir

✅ Basit ve genişletilebilir yapı
